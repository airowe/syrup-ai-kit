Siri AI Developer Preview · iOS 27.3

“In Bluesky, what’s trending right now?”

Siri, on an iPhone, Nov 12 Right now on Bluesky, the trending topics include the reported Microsoft 365 outage, a senator seeking the majority leader post, Jeffries listing Democratic priorities, films watched more than six times, and Jensen Huang resigning from Nvidia.

That’s Siri reading Bluesky’s live trending list in a fork of the open-source Bluesky app. Siri called the app’s tool, the tool asked Bluesky’s public API, and Siri answered. The tool is a few lines of JSON, turned into Swift by Syrup AI Kit when the app builds.

One JSON entry per thing people ask

  1. You ask Siri“In Bluesky, what’s trending right now?”
  2. Siri picks the toolGetTrendingTopics, from its title and description
  3. The tool calls the APIpublic.api.bsky.app, app.bsky.unspecced.getTrendingTopics
  4. Siri answersfrom the reply template, with the five top topics filled in
siri-tools.jsonBluesky fork
{
  "name": "GetTrendingTopics",
  "title": "Get Trending Topics",
  "description": "Says what's trending on Bluesky right now: the top topics people are posting about.",
  "request": {
    "method": "GET",
    "url": "https://public.api.bsky.app/xrpc/app.bsky.unspecced.getTrendingTopics?limit=5"
  },
  "reply": "Trending on Bluesky: {topics.displayName}.",
  "returns": "value"
}
The fork’s second tool takes a parameter “In Bluesky, look up the profile bsky.app and tell me how many followers it has.”
Siri The Bluesky account @bsky.app has 35,642,419 followers .

GetProfile fills handle from what you said and calls app.bsky.actor.getProfile. Siri’s reply is quoted exactly, stray space included.

Tested through Siri on an iPhone

Siri Evaluations ask Siri the same question several times on the phone and check both the tool it called and what it said. The Bluesky fork, on iOS 27.3:

“What’s trending right now?” called GetTrendingTopics2 of 2 complete runs
“Look up the profile bsky.app” called GetProfile and said the follower count4 of 4 complete runs

Each evaluation ran 5 times. 3 trending runs and 1 profile run were cut short before a tool call was recorded, so Apple’s own pass rates read 40% and 80%. Syrup AI Kit’s summary separates those cut-short runs from real failures, and none of the complete runs failed.

expo-syrup-ai-kit

An Expo config plugin. Describe tools in JSON and it writes the Swift at prebuild.

SyrupAIKit

Wraps API code you already have in a Siri tool. Keeps to Siri’s time budget and turns failures into sentences Siri can say.

SyrupAIEvalKit

Runs Siri Evaluations on a device and records what every tool call did in each run.

siri-ai-eval

Summarizes results and tells real failures apart from runs that were cut short.

Add it to your Expo app

npx expo install expo-syrup-ai-kit expo-app-intents
npx expo-app-intents init --examples minimal

Describe your tools in siri-tools.json, add ["expo-syrup-ai-kit", { "tools": "./siri-tools.json" }] to your app.json plugins after "expo-app-intents", then prebuild with the preview on and run on a phone set up for Siri AI:

SIRI_AI_PREVIEW=1 CP_CACHE_DIR="$PWD/.cp-cache" LANG=en_US.UTF-8 npx expo prebuild -p ios
npx expo run:ios --device

Native Swift app: add the package https://github.com/airowe/syrup-ai-kit from 0.4.0. Coding agent: npx skills add airowe/syrup-ai-kit, then ask it to “make my app work with Siri AI”.
